# Language packs

Built-in packs live in `src/is2_re/locales/<locale>/`. Each pack consists of `language.json` and `messages.json`. See [`docs/LOCALIZATION_RU.md`](docs/LOCALIZATION_RU.md) for the complete schema, creation commands, validation, fallback behavior, and RTL notes.

The `_template` folder is not loaded as a language. It contains the full source catalog used to create community translations.
