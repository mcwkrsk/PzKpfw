# PzKpfw 9.10.0

PzKpfw — экспериментальный открытый редактор проектов формата `.is2`. Он позволяет работать с действиями, параметрами, объектами, декомпозицией, спецификациями и матричной диаграммой в едином интерфейсе. Проект представляет собой самостоятельную реализацию и не является официальной версией ИС-2.

## Возможности

- Формирование СПД: дерево действий, схема с сеткой, выбор последовательности, альтернативы, цикла и элементарного действия. Кнопка «Вид ИС-2» переключает раскладку на листы по образцу ИС-2; выбор листа находится под панелью команд.
- Полная диаграмма декомпозиции и отдельные листы составных действий; масштабирование и экспорт SVG. На вкладках СПД и декомпозиции можно развернуть схему на всю рабочую область и вернуться кнопкой или клавишей Esc. В полноэкранном СПД кнопка «Назад по схеме» возвращает предыдущий вид после перехода в действие.
- Редактирование параметров и объектов; отображение имени объекта рядом с его ID.
- Матричная диаграмма с группировкой параметров по объектам и подсказками; экспериментальные спецификации и экспорт.
- Тёмная и светлая темы, отмена и повтор, проверка структуры проекта, резервное копирование и сравнение файлов.
- Модульные языковые пакеты: русский, английский, украинский, немецкий, французский, испанский, иврит, греческий и дореформенный русский. Текущие 1107 строки каталога заполнены во всех встроенных языках; новые или пользовательские непереведённые строки отображаются по-русски. Новые языки можно добавлять JSON-пакетами без изменения Python-кода. См. [руководство по локализации](docs/LOCALIZATION_RU.md).
- Подсказки к кнопкам при наведении: включаются и отключаются в верхней панели на любой вкладке; настройка сохраняется между запусками.

**Состояние совместимости:** отображение декомпозиции, структурных символов, матрицы и спецификаций восстановлено приблизительно; полное соответствие ИС-2 не подтверждено. Символ `~` в матрице обозначает предположительно вычисленную информацию, которая не записывается в исходный файл. Используйте копии важных проектов и проверяйте результаты в оригинальной программе. Подробнее: [сравнение с ИС-2](docs/IS2_COMPARISON_2026-11-08_RU.md).

## Установка в Windows

Скачайте `PzKpfw-Setup-<версия>.exe` со страницы [Releases](https://github.com/mcwkrsk/PzKpfw/releases) и запустите его. Права администратора не нужны. Установщик сам скачает свою среду выполнения, около 27 МБ, и проверит её контрольную сумму. Установленный Python не нужен и не затрагивается. Программа появится в «Пуске», файлы `.is2` можно открывать двойным щелчком. Обновления программа предлагает сама. Дополнительные возможности ставятся через «Модули → Управление модулями…».

Как выпускать версии и публиковать модули: [docs/RELEASES_AND_MODULES_RU.md](docs/RELEASES_AND_MODULES_RU.md).

## Запуск из исходников

Нужен Python 3.10 или новее с Tkinter. Для экспорта отчёта в Word дополнительно выполните `py -3 -m pip install -r requirements.txt`; остальные функции работают без этих библиотек. Пункт «Экспорт → Отчёт в DOCX…» создаёт титульный лист, диаграммы, редактируемые формы и части матрицы; разделы без данных остаются для заполнения. Проверьте полученный документ и соответствие форм требованиям преподавателя.

В Windows запустите `Запустить_PzKpfw.bat` (можно перетащить на него файл `.is2`). Из командной строки в корне проекта:

```bat
set PYTHONPATH=%CD%\src
py -3 -m is2_re.gui
```

На Linux/macOS при установленном Tkinter и графической среде:

```sh
PYTHONPATH=src python3 -m is2_re.gui
```

Замер прокрутки матрицы: `py -3 tools\benchmark_matrix_gui.py "путь\к\работе.is2"` (с `PYTHONPATH` как выше). Без пути используется тестовый проект; файл не сохраняется и не изменяется. Скрипт выводит медиану и 95-й процентиль времени обновления и оценку памяти Python; результаты зависят от оборудования и проекта.

## Тестирование

```sh
PYTHONPATH=src python -m unittest discover -s tests -p 'test_*.py' -v
```

В Windows команду задания переменной замените на `set PYTHONPATH=%CD%\src`. GitHub Actions запускает тесты на Python 3.10–3.13 и проверку запуска интерфейса на Windows; при выпуске версии установщик дополнительно устанавливается, запускается и удаляется на Windows.
