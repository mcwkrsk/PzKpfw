# Жизненный цикл ресурсов интерфейса

- Страницы динамических вкладок декомпозиции удаляются из notebook и уничтожаются при перестроении. Обычный `forget()` по-прежнему только отвязывает страницу: это стандартное поведение для случаев, где страницу нужно сохранить.
- Меню экспорта и контекстное меню СПД создаются по одному экземпляру на окно и переиспользуются; окно-владелец уничтожает их при закрытии. Уничтожать меню сразу после `tk_popup()` нельзя: обработка выбора продолжается в цикле событий Tk.
- Заголовки графа обрабатываются единым обработчиком нажатия на холст; новые обработчики при каждой перерисовке не регистрируются. По тегу определяется нажатая группа.
- Ожидающие перерисовки схемы и сетки таблицы отменяются при уничтожении виджета. Подсказка матрицы закрывается при завершении приложения.
- Данные схем, форм и матриц рассчитываются заново на текущей модели; долговечный кеш, требующий сброса после правок, не добавлен. Обработчики ожидаемых повреждений структуры сохранены, но не перехватывают произвольные ошибки программирования.

Локальная проверка включает 26 unit-тестов, в том числе повторное создание меню, удаление 1000 условных страниц и отмену задания. `tools/smoke_gui.py` дополнительно содержит цикл с настоящими Tk-виджетами и доступен для запуска в графической среде Windows; его выполнение в окружении без дисплея не подтверждено. Тесты не являются доказательством отсутствия любых утечек: для продолжительной проверки необходимо измерять память процесса и ресурсы окон Windows при работе с крупными проектами.
