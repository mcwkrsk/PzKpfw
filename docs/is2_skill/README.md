# Набор инструкций PzKpfw для проектов ИС-2

Актуальная версия: `v1`.

Этот каталог заменяет монолитный `is2_skill.md`. В старом файле одновременно находились инструкции, описание
формата, копии программного кода, XML-заготовки и примеры. Такая структура дублировала реализацию PzKpfw и могла
расходиться с ней после изменений.

## Состав версии

- `v1/instructions.md` — правила подготовки безопасного плана;
- `v1/protocol.schema.json` — схема внешнего JSON-контракта;
- `v1/examples/valid_minimal.json` — принимаемый и исполняемый пример;
- `v1/examples/invalid_*.json` — отрицательные примеры;
- `v1/test_cases.json` — ожидаемый результат каждого примера.

Исполняемая логика не копируется в документацию. Её единственные источники истины:

- `src/is2_re/assistant/models.py` — строгий протокол версии 1;
- `src/is2_re/assistant/executor.py` — атомарное применение операций;
- `src/is2_re/document.py` — модель, проверка и сохранение `.is2`;
- `src/is2_re/methodology/` — проверенные инженерные формулы и ссылки.

Примеры проверяются тестом `tests/test_is2_skill_package.py`: успешный пример исполняется на новом проекте и
проходит цикл сохранение–повторное открытие, ошибочные примеры должны быть отклонены на указанном этапе.
