IS-2 STUDIO — Stage 2 Desktop Alpha
===================================

Это независимый настольный редактор проектов .is2. Он не запускает оригинальный
IS.exe и не использует его DLL. Редактор реализован на Python + Tkinter.

ЗАПУСК НА WINDOWS
-----------------
1. Установите Python 3.10 или новее с python.org.
2. При установке Python оставьте включённым Tcl/Tk (обычно он включён по умолчанию).
3. Распакуйте весь архив в обычную папку.
4. Запустите файл «Запустить_IS2_Studio.bat».
5. Нажмите «Открыть» и выберите проект .is2.

Можно передать проект прямо при запуске: перетащите файл .is2 на .bat.

Необязательная установка wheel без скачивания зависимостей: запустите
«Установить_IS2_Studio.bat». Для непосредственного запуска установка не нужна.

На Linux/macOS: запустите ./Запустить_IS2_Studio.sh (нужны Python 3 и Tkinter).

ВОЗМОЖНОСТИ ЭТОЙ ВЕРСИИ
-----------------------
- Создание пустого проекта на основе восстановленного общего XML-конверта.
- Открытие, структурная проверка и сохранение .is2.
- Редактирование паспорта проекта и сведений о пользователе.
- Дерево и графическая схема PrimaryModel/spd: добавление корневых и дочерних действий,
  изменение и удаление действий с обслуживанием sibling-chain.
- CRUD для параметров и объектов.
- CRUD для ConceptModel/cs: SubjectCategory (pk), SCBinaryLink (link),
  проверка endpoint-ов и пересчёт восстановленного AutoRange.
- Просмотр spz/content и исходного XML; неподдерживаемые разделы сохраняются
  как непрозрачные поддеревья, без намеренной нормализации их содержимого.
- Атомарная запись файла и проверка перед сохранением.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
------------------
- Новый пустой проект собран по восстановленному общему конверту; его приём оригинальной программой не подтверждён.
- Это Desktop Alpha, а не полная функциональная замена оригинальной IS-2.
- spz/content, matrix и функциональность пяти оригинальных плагинов пока
  не имеют полноценного редактируемого интерфейса.
- Нет native Windows .exe installer; запуск идёт через Python/Tkinter.
- Проверка выполнена на XML-образцах и статических контрактах. Оригинальный
  IS.exe в Windows runtime не запускался; load-save-open в оригинале ещё
  не подтверждён.
- XML сохраняется семантически, но не побайтно идентично QDomDocument.
- Перед работой создавайте копию важных проектов.
