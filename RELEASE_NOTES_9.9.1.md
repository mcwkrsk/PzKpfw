# PzKpfw 9.9.1

Экспериментальный редактор проектов формата `.is2`.

В состав версии входят формирование СПД, представление по образцу ИС-2 с навигацией по листам и циклами, декомпозиция, редактирование параметров и объектов, спецификации, матричная диаграмма и экспорт отчёта в DOCX. Для матрицы и схем уменьшена часть повторных перерисовок; результат зависит от компьютера и размера проекта.

Windows-приложение собирается из исходников с помощью `Собрать_автономный_EXE.bat`. При отсутствии Python 3.12 x64 сборщик скачает официальный установщик. Для запуска готового приложения папка `_internal` должна находиться рядом с EXE. Сборка и проверка пользовательского интерфейса Windows для этого пакета ещё не выполнены; готовый EXE в архив не включён.

Часть представлений и обозначений восстановлена по доступным данным; полная совместимость с ИС-2 не подтверждена. Подробности — в README и `docs/IS2_COMPARISON_2026-11-08_RU.md`.
