# PzKpfw 9.9.1

PzKpfw — экспериментальный открытый редактор проектов формата `.is2`. Он позволяет работать с действиями, параметрами, объектами, декомпозицией, спецификациями и матричной диаграммой в едином интерфейсе. Проект представляет собой самостоятельную реализацию и не является официальной версией ИС-2.

## Возможности

- Формирование СПД: дерево действий, схема с сеткой, выбор последовательности, альтернативы, цикла и элементарного действия. Кнопка «Вид ИС-2» переключает раскладку на листы по образцу ИС-2; выбор листа находится под панелью команд.
- Полная диаграмма декомпозиции и отдельные листы составных действий; масштабирование и экспорт SVG. На вкладках СПД и декомпозиции можно развернуть схему на всю рабочую область и вернуться кнопкой или клавишей Esc. В полноэкранном СПД кнопка «Назад по схеме» возвращает предыдущий вид после перехода в действие.
- Редактирование параметров и объектов; отображение имени объекта рядом с его ID.
- Матричная диаграмма с группировкой параметров по объектам и подсказками; экспериментальные спецификации и экспорт.
- Тёмная и светлая темы, отмена и повтор, проверка структуры проекта, резервное копирование и сравнение файлов.
- Подсказки к кнопкам при наведении: включаются и отключаются в верхней панели на любой вкладке; настройка сохраняется между запусками.

**Состояние совместимости:** отображение декомпозиции, структурных символов, матрицы и спецификаций восстановлено приблизительно; полное соответствие ИС-2 не подтверждено. Символ `~` в матрице обозначает предположительно вычисленную информацию, которая не записывается в исходный файл. Используйте копии важных проектов и проверяйте результаты в оригинальной программе. Подробнее: [сравнение с ИС-2](docs/IS2_COMPARISON_2026-11-08_RU.md).

## Запуск в Windows

Для экспорта отчёта в Word установите дополнительные зависимости командой
`py -3 -m pip install -r requirements.txt` в папке проекта. Остальные функции
редактора работают без них. Сборщик EXE устанавливает их автоматически.
Пункт «Экспорт → Отчёт в DOCX…» создаёт титульный лист, диаграммы,
редактируемые формы и части матрицы; разделы без данных остаются для заполнения.
Проверьте полученный документ и соответствие форм требованиям преподавателя.

Для замера прокрутки матрицы непосредственно в Windows можно выполнить
`set PYTHONPATH=%CD%\src` и затем `py -3 tools\benchmark_matrix_gui.py "путь\к\работе.is2"`.
Без пути используется тестовый проект. Замер не сохраняет и не изменяет файл.
После сборки можно вместо `py -3` указать `.venv-build-py312\Scripts\python.exe`.
Скрипт выводит медиану и 95-й процентиль времени обновления при прокрутке и
выделении, а также оценку памяти Python. Это замер исходной версии интерфейса,
не измерение собранного EXE; результаты зависят от оборудования и проекта.

1. Установите Python 3.10 или новее с поддержкой Tkinter и включите добавление Python в PATH.
2. Скачайте репозиторий как ZIP и распакуйте **полностью**.
3. Запустите `Запустить_PzKpfw.bat`, затем откройте файл `.is2` в меню программы.

Из командной строки в корне проекта:

```bat
set PYTHONPATH=%CD%\src
py -3 pzkpfw_standalone_entry.py
```

На Linux/macOS при установленном Tkinter и графической среде:

```sh
PYTHONPATH=src python3 pzkpfw_standalone_entry.py
```

## Сборка автономного EXE

На 64-битной Windows запустите `Собрать_автономный_EXE.bat`. При отсутствии Python 3.12 с Tkinter сборщик скачивает официальный установщик Python 3.12.10, проверяет цифровую подпись и устанавливает Python для текущего пользователя в `%LOCALAPPDATA%\PzKpfw\BuildPython312`, не меняя PATH. Для этого и установки библиотек в окружение `.venv-build-py312` нужен интернет. Скрипт выполняет тесты и создаёт `dist/PzKpfw/PzKpfw.exe`, проверяя наличие Python DLL и tkinter в папке `_internal`. Для запуска на другом компьютере скопируйте **всю папку** `dist/PzKpfw`: установка Python и доступ в интернет на целевом компьютере не нужны.

Сборщик также помещает `PzKpfw.exe` и папку `_internal` в основную папку проекта, рядом с BAT-файлом. Не перемещайте EXE отдельно от `_internal`; для удобного запуска с рабочего стола создайте ярлык. Предыдущие одноимённые файлы в основной папке сохраняются с суффиксом `.backup-...`.

Этот вариант не распаковывает всё приложение при каждом запуске, как прежний `--onefile`. Это может сократить время запуска, но само по себе не гарантирует скорость интерфейса. Для проверки на Windows и получения архива можно вручную запустить GitHub Actions → `Windows application build`: сценарий проверяет интерфейс, измеряет прокрутку матрицы, собирает приложение и проверяет, что оно запускается. Результаты доступны в артефактах `PzKpfw-Windows` и `matrix-benchmark`. Измерение использует синтетический проект и оборудование GitHub, поэтому производительность на конкретном ноутбуке нужно проверять отдельно. Готовый EXE в этом архиве не поставляется; текущая сборка на Windows ещё не проверена.

## Тестирование

```sh
PYTHONPATH=src python -m unittest discover -s tests -p 'test_*.py' -v
```

В Windows команду задания переменной замените на `set PYTHONPATH=%CD%\src`. В архив включён ограниченный набор регрессионных тестов, который работает без приватных файлов и отсутствующих инструментов старой сборки. Более широкий исходный набор репозитория требует дополнительных файлов; его нельзя считать пройденным. GitHub Actions запускает этот набор на Python 3.10–3.13 и дополнительно выполняет короткую проверку запуска интерфейса на Windows.

## Публикация в GitHub

Архив — снимок исходников для проверки и последующего добавления в репозиторий, а не готовый релиз Windows. Сравните его с актуальной веткой и перенесите нужные файлы, затем проверьте `git status` и GitHub Actions. При переносе поверх старой версии удалённые из снимка устаревшие файлы не исчезнут из Git автоматически: проверьте их отдельно. Личные проекты, системные файлы, сборки, кэши и исполняемые файлы оригинальной ИС-2 не включены.
