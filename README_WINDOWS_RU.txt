PzKpfw — Windows x64 GUI launcher

ПРОЧИТАЙТЕ ПЕРЕД ЗАПУСКОМ
Этот PzKpfw.exe — настоящий 64-битный Windows исполняемый файл (PE32+)
со встроенной иконкой, но НЕ автономная сборка. Для работы необходим
Python 3.10+ (рекомендуется 3.12) с модулем tkinter.

Для запуска:
1. Установите Python с python.org для Windows x64 и включите Add Python to PATH.
   Обычная версия Python для Windows содержит tkinter.
2. Распакуйте архив целиком, не отделяйте PzKpfw.exe от папки src.
3. Запустите PzKpfw.exe (или перетащите файл .is2 на значок).

Логотип Tiger отображается в интерфейсе. Иконка в заголовке и
панели задач — шестерня с искрами на белом фоне.

Если нужен ОДИН автономный EXE без Python, на компьютере с Windows
откройте PowerShell в этой папке и запустите:
  powershell -ExecutionPolicy Bypass -File .\build_windows_standalone.ps1
Сценарий требует интернета для установки PyInstaller и сформирует
файл dist\PzKpfw.exe, в котором Python и ресурсы уже упакованы.

Этот исходный Windows-загрузчик собран в Linux кросс-компилятором LLVM.
Его структура и импорты проверены, но запуск на Windows НЕ тестировался.
