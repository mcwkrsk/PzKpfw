# Протокол ИИ-ассистента PzKpfw, версия 1

## Назначение

Протокол описывает пакет предложений ассистента. Ответ модели не является XML и не исполняется как программный код. PzKpfw принимает только известные поля и разрешенные операции, применяет их к копии документа и возвращает результат после проверки.

## Пример

```json
{
  "protocol_version": 1,
  "summary": "Добавить элементы схемы цилиндрической передачи",
  "assumptions": [
    "Численные вычисления для курсовой не требуются"
  ],
  "questions": [],
  "operations": [
    {
      "operation_id": "object-1",
      "type": "add_object",
      "arguments": {
        "name": "Цилиндрическая передача",
        "attributes": {
          "kind": "gear"
        }
      }
    },
    {
      "operation_id": "parameter-1",
      "type": "add_parameter",
      "arguments": {
        "attributes": {
          "name": "Передаточное отношение",
          "sign": "u",
          "unit": "-"
        }
      }
    }
  ],
  "sources": [
    {
      "title": "Детали машин",
      "locator": "таблица 6.15, страницы 57–58"
    }
  ],
  "manual_checks": [
    "Сверить состав параметров и связи действий с заданием"
  ]
}
```

`operation_id` можно не указывать: тогда PzKpfw присвоит локальный номер `O0001`, `O0002` и так далее. В одном пакете идентификаторы не должны повторяться.

## Разрешенные операции

### `add_object`

Обязательные аргументы:

- `name` — непустое название объекта.

Необязательные аргументы:

- `attributes` — дополнительные строковые или целочисленные атрибуты. Поля `id` и `name` здесь запрещены: ими управляет PzKpfw.

### `rename_object`

Обязательные аргументы:

- `object_id` — идентификатор существующего объекта;
- `name` — новое непустое название длиной не более 240 символов.

Операция меняет только название. Произвольные атрибуты и сырой XML не принимаются. Если объект не найден, весь пакет отклоняется без частичных изменений.

### `add_action`

Обязательные аргументы:

- `name`;
- `action_type`.

Необязательные аргументы:

- `formalization`;
- `status`;
- `mark`;
- `symbol`;
- `level`;
- `number`;
- `parent_id`;
- `parent_operation_id` — ссылка на более раннюю операцию `add_action`, результат которой станет родительским действием;
- `alternatives` — массив текстовых альтернатив.

### `set_action_formula`

Обязательные аргументы:

- `expression` — формула обычным текстом;
- `reference` — номер формулы или краткая ссылка на проверенный источник.

Действие задаётся ровно одним из полей:

- `action_id` — идентификатор существующего элементарного действия;
- `action_operation_id` — `operation_id` более ранней операции `add_action` в том же плане.

Операция разрешена только для действия типа `0` (элементарного). Она записывает формулу со ссылкой в нативное поле примечания `mark` и устанавливает аналитическую формализацию `0`. Составные действия и произвольные дополнительные атрибуты отклоняются.

### `add_parameter`

Обязательный аргумент `attributes` должен содержать непустое строковое поле `name`. Поле `id` запрещено и назначается PzKpfw.

Необязательный `object_operation_id` связывает параметр с объектом, созданным более ранней операцией `add_object` в том же пакете. Модель ссылается на `operation_id`, а реальный внутренний ID подставляет PzKpfw. Ссылка вперёд или ссылка на операцию другого типа отклоняется атомарно.

### `add_action_parameter_link`

Обязательные аргументы:

- `role` — `function`, `argument` или `default_argument`.

Действие задаётся ровно одним из `action_id` или `action_operation_id`, а параметр — ровно одним из
`parameter_id` или `parameter_operation_id`. Поля с суффиксом `_operation_id` ссылаются на более ранние операции
`add_action` и `add_parameter` в том же плане; локальные ID подставляет исполнитель PzKpfw.

Необязательный `power` задаёт целочисленную кратность связи и по умолчанию равен `1`. Операция использует консервативный редактор нативной матрицы: непрозрачные записи, дубликаты, вторая функция одного действия и связь с составным действием отклоняются.

### `update_parameter`

Обязательные аргументы:

- `parameter_id` — идентификатор существующего параметра;
- `changes` — непустой объект изменяемых полей.

Идентификатор параметра изменять нельзя. Значение `null` удаляет соответствующий необязательный атрибут.

### `renumber_actions`

Необязательный аргумент `symbol` задаёт один печатный символ кода и по умолчанию равен `z`. Операция пересчитывает `symbol`, `level` и `number` по порядку дерева, не меняя ID и связи.

Используется алгоритм PzKpfw с глобальной нумерацией внутри каждого уровня. Это проверенное внутреннее приближение, а не подтверждённая копия нативной функции `codeStructure()` из ИС-2; данный факт показывается в документации и не скрывается от пользователя.

## Правила безопасности

- Неизвестные поля и операции отклоняются.
- Ответ ограничен размером 2 МиБ.
- Один пакет содержит не более 128 операций.
- План с неотвеченными `questions` не выполняется.
- Модель не назначает внутренние идентификаторы новых записей.
- Все операции выполняются на клоне `ProjectDocument`.
- При ошибке любой операции исходный документ остается неизменным.
- Новые ошибки глубокой валидации запрещены.
- Перед выдачей результата XML повторно открывается, сравнивается семантически и проверяется на стабильность повторной сериализации.
- Принятие результата в интерфейсе будет отдельным явным действием пользователя.

## Сводка проекта

Для будущего подключения модели предусмотрена отдельная сводка версии 1. Она содержит название проекта, количества действий, параметров, объектов и матричных связей, распределение типов действий и ограниченный список замечаний валидатора. Сырой XML, содержимое файла и произвольные локальные файлы в сводку не входят.

Проверка проекта не является необязательной операцией модели: глубокая валидация и проверка сериализации автоматически выполняются после каждого пакета до показа результата пользователю.

## Текущие ограничения

Версия 1 пока не содержит удаления записей, изменения сырого XML, запуска команд, доступа к файлам, автоматического сохранения и сетевых операций. Поддержка переименования действий будет добавляться отдельной проверяемой операцией.
