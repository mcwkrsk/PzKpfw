# OCR и черновик пояснительной записки

Функция находится во вкладке «OCR и отчёт» окна ассистента.

## OCR

1. Выберите PDF.
2. Укажите только нужные страницы: например, `5, 8-10`.
3. Выберите папку результатов.
4. Нажмите «Распознать выбранные страницы».

За один запуск разрешено не более 20 страниц. Каждая страница отдельно преобразуется в PNG, поэтому распознанный
текст сохраняет связь с номером страницы и изображением-источником. Для слов сохраняется уверенность OCR.
Фрагменты с низкой уверенностью, формулами или большим количеством чисел помечаются для ручной сверки.

Распознавание выполняется локально через Tesseract с языками `rus+eng`. Если Tesseract или русский языковой пакет
не установлен, PzKpfw сообщает об этом и не изменяет PDF. Страницы не отправляются в интернет.

## Экспорт отчёта

Кнопка «Экспортировать черновик отчёта» создаёт:

- `coursework_report.md` — структура проекта, таблица параметров, допущения и OCR-фрагменты;
- `manual_checks.txt` — отдельный список ручных проверок;
- `ocr_manifest.json` — источник PDF, страницы, изображения, уверенность и причины проверки, если OCR выполнялся.

Если открыт проверенный предпросмотр плана ассистента, отчёт строится по его кандидату и включает допущения и
ручные проверки плана. Экспортированный документ остаётся черновиком: инженерные формулы, коэффициенты и OCR нужно
сверить по исходной методичке.
