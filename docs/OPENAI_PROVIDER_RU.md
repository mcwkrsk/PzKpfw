# Подключение ИИ через ChatGPT

PzKpfw использует официальный поток **Continue with ChatGPT** для открытых
настольных приложений. Пользователю не нужен API-ключ: после нажатия кнопки
вход продолжается в системном браузере, а доступ к модели расходует разрешённый
лимит подходящего плана ChatGPT.

## Как войти

1. Откройте «ИИ-ассистент» → «Запрос модели».
2. Нажмите «Войти через ChatGPT».
3. В браузере выберите учётную запись и подтвердите доступ PzKpfw.
4. Вернитесь в программу и отправьте запрос.

Первый вход автоматически регистрирует локальную установку PzKpfw как
открытый OAuth-клиент. Пароль, история разговоров и API-ключ приложению не
передаются. Токены хранятся отдельно от проектов и защищаются Windows DPAPI для
текущего пользователя Windows.

## Что отправляется модели

Только ограниченная обезличенная сводка структуры проекта и текст запроса.
Исходный XML, название проекта и тексты замечаний не отправляются. Ответ модели
проходит локальную проверку протокола и применяется сначала к копии документа.
Запрос идёт потоково с `store: false`, как требует режим использования плана
ChatGPT.

Если запрос содержит номер варианта из локальной методички, ассистент строит
схему предметной задачи для ИС-2: декомпозицию действий, символические
параметры, ссылки на формулы и потоки данных. Численные значения не вычисляются
и не запрашиваются, поскольку курсовая посвящена моделированию расчётной схемы.

## Ограничения и отключение

Использование учитывается в лимите плана ChatGPT и может быть ограничено
настройками самой учётной записи. Отключить локальный сеанс можно кнопкой
«Отключить»; управление разрешением приложения также доступно в настройках
ChatGPT. Подпись токена личности проверяется локально по открытому ключу OpenAI.
