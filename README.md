# PzKpfw

PzKpfw — экспериментальный открытый редактор проектов формата `.is2`. Он позволяет работать с действиями, параметрами, объектами, декомпозицией, спецификациями и матричной диаграммой в едином интерфейсе. Проект представляет собой самостоятельную реализацию и не является официальной версией ИС-2.

## Возможности

- Формирование СПД: дерево действий, схема с сеткой, выбор последовательности, альтернативы, цикла и элементарного действия.
- Полная диаграмма декомпозиции и отдельные листы составных действий; масштабирование и экспорт SVG.
- Редактирование параметров и объектов; отображение имени объекта рядом с его ID.
- Матричная диаграмма с группировкой параметров по объектам и подсказками; экспериментальные спецификации и экспорт.
- Тёмная и светлая темы, отмена и повтор, проверка структуры проекта, резервное копирование и сравнение файлов.

**Состояние совместимости:** отображение декомпозиции, структурных символов, матрицы и спецификаций восстановлено приблизительно; полное соответствие ИС-2 не подтверждено. Символ `~` в матрице обозначает предположительно вычисленную информацию, которая не записывается в исходный файл. Используйте копии важных проектов и проверяйте результаты в оригинальной программе. Подробнее: [сравнение с ИС-2](docs/IS2_COMPARISON_2026-11-08_RU.md).

## Запуск в Windows

1. Установите Python 3.10 или новее с поддержкой Tkinter и включите добавление Python в PATH.
2. Скачайте репозиторий как ZIP и распакуйте **полностью**.
3. Запустите `Запустить_PzKpfw.bat`, затем откройте файл `.is2` в меню программы.

Из командной строки в корне проекта:

```bat
set PYTHONPATH=%CD%\src
py -3 pzkpfw_standalone_entry.py
```

На Linux/macOS при установленном Tkinter и графической среде:

```bash
PYTHONPATH=src python3 pzkpfw_standalone_entry.py
```

## Сборка автономного EXE

На Windows запустите `Собрать_автономный_EXE.bat`. Скрипт устанавливает PyInstaller через pip (нужен интернет) и создаёт `dist/PzKpfw.exe`. Готовый EXE в исходниках не поставляется. Сборка и визуальное тестирование Windows не выполнялись для текущего архива.

## Тестирование

```sh
PYTHONPATH=src python -m unittest discover -s tests -p 'test_*.py' -v
```

В Windows команду задания переменной замените на `set PYTHONPATH=%CD%\src`. В архив включён ограниченный набор регрессионных тестов, который работает без приватных файлов и отсутствующих инструментов старой сборки. Более широкий исходный набор репозитория требует дополнительных файлов; его нельзя считать пройденным. GitHub Actions запускает этот набор на Python 3.10–3.13 и дополнительно выполняет короткую проверку запуска интерфейса на Windows.
